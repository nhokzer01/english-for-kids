# English for Kids

A mobile vocabulary learning app for children, built around super-memory learning techniques.

## Project Goal

Help kids (ages ~4-10) build a strong English vocabulary through playful, interactive practice. The learning methodology is based on super-memory / spaced-repetition principles:

- **Spaced repetition**: words resurface at scientifically-timed intervals so they move into long-term memory.
- **Association learning**: each word is tied to images, sounds, and simple stories so kids remember by association, not rote memorization.
- **Interactive practice**: flashcards, matching games, listen-and-repeat, and picture quizzes keep engagement high.
- **Progress loops**: short daily sessions with rewards and streaks to build a learning habit.

## Expected Tech Stack

- **Mobile**: native iOS (Swift/SwiftUI) and native Android (Kotlin/Jetpack Compose)
- **Backend/CMS**: headless CMS for managing vocabulary content, images, and audio
- **Audio**: text-to-speech + recorded pronunciation
